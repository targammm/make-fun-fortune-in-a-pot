A one-line fortune for a houseplant on the windowsill: kind, funny, and written for this plant in this window. A deterministic Python program writes the fortune to `/output/entry.txt` for make.fun's "Fortune in a Pot" bounty.

## The fortune

> By Friday, one brave root will find the drainage hole, and your human will call it ambition.

92 characters, one line, no trailing newline. The program validates the line against the gate (1–120 characters, single line, not only whitespace) before writing it, and writes the exact same bytes on every run.

## Why this line

The judge's rubric, in its own order: it is a fortune about this plant's own future (a root finding the drainage hole); the joke is small and lands for plant lovers (the human misreads a root as ambition); it is warm — the plant is brave, the human is fond, no doom, no wilting, no mockery; it carries a fortune's cadence ("By Friday... will..."); and at 92 characters every word earns its place, written for this pot on this windowsill rather than any plant in any room.

## Run it

```sh
python3 main.py
```
